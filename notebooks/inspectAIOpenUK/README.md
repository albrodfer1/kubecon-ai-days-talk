# inspectAIOpenUK

## Visualize results

```shell
inspect view
```

## Instructions

1. Run notebook. The results will be saved in you google drive
2. Install inspect on your local machine using poetry and the lock files in the repo
3. Download the folder with the results and run the following to visualize the evaluation report:

```shell
poetry run inspect view
```

4. The command above should expose a web page locally on port `7575`.
